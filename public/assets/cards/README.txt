Card art goes here. One PNG per card, filename = the card id, e.g. drv-mansell.png
Anything missing falls back automatically to a coloured placeholder with the card name on it.

Generate art at 3:4 PORTRAIT. The same file is centre-cropped three ways (3:4 grid, 1:1 squad
slot, 16:10 detail hero), so keep the subject inside the central horizontal band and keep the
bottom ~22% dark and quiet — the frosted name plate sits over it.

Copy-paste ChatGPT prompts (grid method): /docs/card-art-prompts.md
Slicer for the generated grids:           /tools/slice-grid.html  (open in a browser)
The rules behind them:                    /docs/card-art-brief.md
